The accountability gap

Observability tooling reports that agents are healthy — latency, tokens, uptime. It cannot answer the four questions a regulator, an auditor or your board will ask after an incident: which agent invoked which tool · what data it reached · whether it was persuaded · which path an attacker would take first. MAS's SAFR paper (July 2026) and IMDA's agentic-AI framework (2026) now set exactly those expectations: authorised scope, runtime assessment, and records retained for accountability.
